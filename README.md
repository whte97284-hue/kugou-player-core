## 📖 项目简介

**酷狗音频解码终端** 是一款基于 Electron + Flask 的桌面应用程序，用于将酷狗音乐的加密格式（KGM/KGG）转换为通用的音频格式（MP3/FLAC）。

本工具采用现代化的终端风格 UI 设计，提供直观的拖拽操作、批量转换、在线播放等功能，让您轻松管理和转换本地的加密音频文件。

### 🌟 为什么选择本工具？

- **简单易用**：拖拽即可转换，无需复杂配置
- **批量处理**：支持同时转换多个文件
- **美观界面**：复古终端风格，多主题可选
- **完全免费**：开源项目，永久免费
- **隐私安全**：纯本地处理，不上传任何数据

## 📥 下载安装

### 便携版

**文件名**: `酷狗音频解码器-2.1.0.exe` (约 80MB)

**特点**:
- 单文件，双击即可运行
- 无需安装，可放在 U 盘携带
- 运行时临时解压，关闭后自动清理

**使用方法**:
1. 下载 `酷狗音频解码器-2.1.0.exe`
2. 双击运行即可

> ⚠️ **注意**: 便携版无法固定到任务栏

---

### 完整版

**文件夹**: `win-unpacked/` (约 160MB)

**特点**:
- 已解压的完整应用
- 可以固定到任务栏
- 启动速度更快

**使用方法**:
1. 将 `win-unpacked` 文件夹复制到目标位置（如 `C:\Program Files\酷狗音频解码终端\`）
2. 运行文件夹中的 `酷狗音频解码终端.exe`
3. 右键任务栏图标 → 选择"固定到任务栏"

> ✅ **推荐**: 如需长期使用，建议使用完整版

## 📘 使用教程

### 转换中心

转换中心是软件的主要功能区域，用于转换加密音频文件。

#### 方法一：拖拽转换

1. 打开软件，确保在"转换中心"页面
2. 将 KGM 或 KGG 文件拖拽到窗口中央的拖放区域
3. 软件会自动开始转换
4. 转换完成后，文件会保存到输出目录

#### 方法二：选择文件

1. 点击拖放区域中的"选择文件"按钮
2. 在文件选择器中选择要转换的文件（支持多选）
3. 确认后自动开始转换

#### 转换进度

- 转换过程中会显示实时进度条
- 每个文件的转换状态会单独显示
- 转换完成后会显示成功或失败信息

---

### 归档库

归档库用于管理所有已转换的音频文件。

#### 功能说明

| 操作 | 说明 |
|------|------|
| **播放** | 点击播放按钮在线试听 |
| **复制** | 将文件复制到剪贴板，可直接粘贴到其他位置 |
| **定位** | 在文件资源管理器中打开文件所在目录 |
| **删除** | 删除该文件（不可恢复） |
| **搜索** | 在搜索框输入关键词搜索文件 |

#### 音频播放器

- 底部播放器支持：播放/暂停、上一首/下一首、进度拖动、音量调节
- 音量设置会自动保存

---

在设置页面可以自定义软件行为。

#### 输出目录

2. 在输入框中输入新的路径
3. 点击"应用"按钮保存设置
4. 设置会自动持久化，下次启动时保留

#### 主题切换

## ❓ 常见问题

### Q1: 转换失败怎么办？

**可能原因**:
- `tools` 文件夹中缺少解码工具
- 文件已损坏或格式不支持

**解决方案**:
1. 确保 `tools/kgg/` 目录下包含 `kgg-dec.exe` 和 `infra.dll`
2. 确保 `tools/kgm/` 目录下包含 `kgm-dec.exe`
3. 尝试重新下载源文件

---

### Q2: 输出的文件在哪里？

**默认位置**: 软件目录下的 `output` 文件夹

**自定义位置**: 在设置页面修改输出目录

**快速定位**: 在归档库中点击文件的"定位"按钮

---

### Q3: 为什么便携版不能固定到任务栏？

便携版每次运行时会解压到临时目录，路径不固定，因此 Windows 无法为其创建固定的快捷方式。

**解决方案**: 使用 `win-unpacked` 完整版

---

### Q4: 软件无法启动？

**可能原因**:
- 有残留进程在运行
- 端口 5000 被占用

**解决方案**:
1. 打开任务管理器
2. 结束所有 `酷狗音频解码终端` 和 `KugouDecoder.exe` 进程
3. 重新启动软件

---

### Q5: 设置没有保存？

设置会保存到 `config.json` 文件。如果无法保存，请检查：
1. 软件所在目录是否有写入权限
2. `config.json` 文件是否被其他程序占用

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户界面层                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              Electron (Chromium)                     │   │
│  │         HTML + CSS + JavaScript 前端                  │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│                      服务层                                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                Flask Web Server                      │   │
│  │              Python 后端 (RESTful API)               │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│                      核心层                                  │
│  ┌────────────────────┐  ┌────────────────────────────┐    │
│  │    kgm-dec.exe     │  │       kgg-dec.exe          │    │
│  │   (KGM 解密工具)    │  │      (KGG 解密工具)         │    │
│  └────────────────────┘  └────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 技术栈详情

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Electron 28.x | 跨平台桌面应用框架 |
| UI 渲染 | Chromium | 网页渲染引擎 |
| 后端框架 | Flask 3.x | Python Web 微框架 |
| 模板引擎 | Jinja2 | HTML 模板渲染 |
| 打包工具 | PyInstaller | Python 应用打包 |
| 构建工具 | electron-builder | Electron 应用构建 |
